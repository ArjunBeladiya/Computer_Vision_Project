# Object Detection and Depth Estimation
This project implements 2D object detection and monocular depth estimation using the YOLO11X model and the KITTI dataset.
The goal is to detect cars in 2D images, estimate their distances using intrinsic camera parameters and geometric transformations, and evaluate performance with Precision–Recall metrics.

# Repo Structure:
  - code: contains Python script
  - output_Final: contains output images
  - KITTI_Selection.zip: it contains selected KITTI images and calibration files used in this project.
  - Report: detailed description of the methodology, results, and evaluation
